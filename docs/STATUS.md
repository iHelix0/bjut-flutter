- “日新工大”是否提供正式 API、SDK、开放平台或校内接口文档。
- 首批数据是否公开，还是必须通过统一身份认证访问。

- Android、iOS、macOS、Windows、Linux 和 Web 中哪些进入首轮真实验收；各平台是否需要额外原生能力。
- 充值的支付渠道、扣款确认、订单状态、回调、退款和失败补偿。
