# MVP 路线与验收

记录日期：2026-09-01

状态：候选方案，已根据功能范围更新，等待接口取证

## MVP 定义

MVP 的核心是完成一条可被真实用户验证的只读闭环：用户按数据源要求完成允许的登录或会话后，能看到课表、个人通知、校园卡余额和校内信息，并能在失败时知道发生了什么。充值属于目标范围，但建议作为只读 MVP 通过后的专项里程碑。

## 候选 MVP

### 方案 A：四类只读数据核心 MVP（当前推荐）

包括课表、个人通知、校园卡余额和信息查阅四类数据。

- 优点：直接覆盖你定义的核心价值，能验证统一认证、数据聚合和跨平台页面。
- 缺点：接口、会话、字段差异和缓存边界会同时出现，必须按数据集拆成独立垂直切片。
- 适用：授权已确认、接口取证可以开始时。

### 方案 B：充值专项（MVP+）

在只读 MVP 稳定后增加校园卡充值。

- 优点：完成完整校园卡闭环，用户价值高。
- 缺点：涉及支付、订单、扣款确认、回调、退款、重复提交和失败补偿，不能只当成一个 POST 请求。
- 前置条件：充值授权、支付渠道和测试环境全部确认，并具备可核对的订单状态。

### 方案 C：微应用入口聚合（可选）

作为信息查阅的补充，整理常用校内微应用入口、可用时间与登录状态，并在允许的 WebView 或外部浏览器中打开。

- 优点：不必复制每个内部系统的数据协议，也可能显著改善入口体验。
- 缺点：更像导航器，不一定满足“读取数据”的目标；单点登录兼容性仍需验证。

## 分阶段步骤

### M0：范围确认

产出：一句用户故事、一个首批数据集、一条可执行的验收标准。

完成条件：`docs/DECISIONS.md` 中 D-001 至 D-005 被确认。

### M1：接口与授权取证

按优先级查找：学校正式 API/文档 → 学校公开网页或公开数据 → 已获授权的本人账号请求。记录域名、请求方式、响应字段、认证、频率限制、个人信息等级，以及授权允许的读取、缓存、展示和代理范围。

本阶段不绕过验证码、证书绑定、设备校验或访问控制，不把真实凭据和完整个人响应保存到项目。

完成条件：四类只读数据各有一份脱敏响应 fixture，或明确证明某类数据当前不能稳定接入；充值另有订单测试材料。

### M2：工程基线

已创建仅含 Android 与 iOS 平台目录的 Flutter 基础工程，桌面/Web 暂不作为首轮验收平台。当前先保留最小依赖和五个功能入口，再按真实接口与会话需求补齐网络、序列化、状态管理和安全存储能力。

完成条件：应用可启动；静态分析通过；基础测试可运行；没有真实密钥或账号数据。

### M3：第一个垂直切片

按课表、通知、余额、信息四个 feature 实现 `DataSource → Repository → Use Case/Controller → Page`。课表、通知和余额使用远端数据源，信息查阅第一版使用可版本化的本地内容包。页面至少呈现加载、内容、空数据、失败和过期状态；四类数据共享认证会话但不共享彼此的远端模型。

完成条件：脱敏 fixture 的解析测试通过；页面测试覆盖主要状态；刷新不会产生重复或失控请求。

### M4：只读真实环境验收

使用项目负责人自己的账号和设备进行人工验收，Agent 不接收账号密码或令牌。检查登录/退出、弱网、无网、会话过期、字段缺失和接口拒绝。

完成条件：四类只读数据的目标场景端到端成功；安全日志检查通过；已知限制被记录。

### M5：充值专项设计与验收

先画出充值状态机：创建订单、待支付、支付中、成功、失败、超时、取消、退款/冲正。实现前确认支付渠道、服务端回调、幂等键、订单查询和用户可见的对账信息。

完成条件：有沙箱或测试账号；重复点击、网络中断、回调延迟和扣款成功但页面失败均可恢复；人工核对订单结果。

### M6：扩展决策

根据真实使用结果决定增加第二个数据集、补充平台、引入后端，或收缩/停止该方向。第一条链路未稳定前不并行堆功能。

## MVP 验收清单

- [ ] 一位目标用户能在目标平台完成约定场景。
- [ ] 数据来源和访问许可有可追溯说明。
- [ ] App 只请求完成场景所必需的数据与权限。
- [ ] 日志、崩溃报告和测试样本不含密码、Cookie、令牌和完整个人信息。
- [ ] 加载、空数据、无网络、超时、会话失效、字段缺失均有明确行为。
- [ ] 解析和 Repository 有自动化测试，页面关键状态有 Widget 测试。
- [ ] 至少一次目标设备人工验收有记录。
- [ ] README 和状态文档没有把候选实现描述成正式授权或已完成产品。

## 明确排除

- 办事提交、审批或修改校内数据；
- 人脸识别、生物特征采集和门禁能力；
- 绕过验证码、速率限制、设备校验、证书绑定或风控；
- 在客户端、仓库或远端服务保存统一身份认证密码；
- 未经确认的后台常驻、通知推送、用户分析和批量采集。
