## 接口样本记录格式

拿到样本后只保留以下脱敏信息：

- 系统名称、用途、公开/个人数据等级；
- 请求方法、路径模板、必要的非敏感参数名；
- 响应字段名、类型、分页和时间字段；
- 会话前置条件、过期表现、错误码和限流提示；
- 采样时间、客户端版本、授权范围和可复现步骤。

不要提交用户名、密码、Cookie、Authorization、设备标识、支付参数、完整姓名学号、完整卡号或完整个人响应。可以把值替换为 `<redacted>`，但保留字段结构和类型。

## 当前推荐取证顺序

1. 课表只读：确认统一认证后能否直接读取个人课表，以及学期、周次、课程、地点字段。
2. 个人通知只读：确认通知列表分页、已读状态和附件链接是否独立于公开教学通知。
3. 校园卡余额只读：确认余额、更新时间、卡状态和最近交易是否同一接口。
4. 信息静态源：选定学校官网/部门页栏目，建立版本化内容包和原文链接。
5. 充值专项：在只读链路稳定后，再确认支付渠道、订单查询、回调、幂等和退款/冲正。
